# twin-data

Written by `.github/workflows/twin-data.yml`, force-pushed on every run on main.
`index.json` lists every scenario's fresh run; `runs/<scenario>/` holds its
manifest, observations, report and engine artifacts, unchanged.
Every value is a scenario estimate, not foundry sign-off.
